# Sophisticated Backpacks (Unofficial Fabric Continuation)

Fancy and functional backpacks: upgradable, dyeable and wearable, with a full set of automation upgrades.

## What it does

Fancy and functional backpacks. A backpack is an item you carry, place down as a
block, or wear on your back — and it keeps its contents wherever it goes:

* **Backpacks** in leather, copper, iron, gold, diamond and netherite tiers; every backpack can be
  dyed and renamed;
* **Upgrades**: pickup, magnet, filter, void, feeding, compacting, cooking, crafting, stonecutter,
  jukebox, stack size, tank, battery, pump, experience pump, refill, restock, deposit, anvil,
  smithing, tool swapper, inception (backpacks inside backpacks), everlasting and infinity;
* **Keybinds** to open the backpack, sort it, run inventory-interaction upgrades, swap tools and
  toggle the first five upgrades on and off;
* **Tool swapper** upgrades read a datapack registry, so packs and tool/source lists can be extended
  by datapacks;
* Mobs can spawn wearing backpacks with loot inside; those backpacks can be logged and listed with
  the ``/sophisticatedbackpacks`` commands.

## Requirements

* Minecraft (Fabric)
* [Fabric API](https://modrinth.com/mod/fabric-api)
* [Sophisticated Core](https://github.com/Huziyang520/Sophisticated-Core-Unofficial-Fabric-Continuation) — required
* [Cloth Config API](https://modrinth.com/mod/cloth-config) — required, it provides the in-game
  configuration screen
* [Mod Menu](https://modrinth.com/mod/modmenu) — optional, adds the config button to the mod list
* Optional integrations: JEI, REI, Jade, Litematica, Chipped, Crafting Tweaks

# Sophisticated Backpacks（非官方 Fabric 移植续）

精致而实用的背包：可升级、可染色、可穿戴，并带全套自动化升级。

## 功能简介

精致而实用的背包。背包是可携带的物品、可放置成方块、也可穿在身上，内容物随之随身：

* **背包** 有皮革、铜、铁、金、钻石、下界合金储层，均可染色与改名；
* 齐全的**升级**：拾取、磁吸、过滤、丢弃、喂食、压缩、烹饪、工作台、切石机、唱片机、堆叠、
  储罐、电池、泵、经验泵、补给、回填、存入、铁砧、锻造台、工具切换、嵌套（背包套背包）、
  不灭、无限；
* **按键**：打开背包、排序、执行库存交互升级、切换工具，以及开关前五个升级；
* **工具切换**升级读取数据包注册表，整合包与数据包可自行扩展工具 / 剑清单；
* 怪物可带着装有战利品的背包生成，并可用 ``/sophisticatedbackpacks`` 指令查询访问记录。
