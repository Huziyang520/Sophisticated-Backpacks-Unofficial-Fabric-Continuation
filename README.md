# Sophisticated Backpacks (Unofficial Fabric Continuation)

This project is a continuation of **Sophisticated Backpacks (Unofficial Fabric port)** originally created by Salandora. It aims to maintain and bring the highly customizable and feature-rich backpack experience to the Fabric ecosystem.

## ✨ Features

* Maintains and updates the core Fabric port functionality from the GPL-3.0 codebase.
* Multiple backpack tiers with extensive customization options.
* Supports various functional upgrades (e.g., auto-pickup, filtering, smelting, feeding, and more).
* Optimized for modern **Fabric** environments and performance.
